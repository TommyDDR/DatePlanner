# Emails envoyés

_Source : spec.md, Clarifications._

## Décision

Le créateur reçoit les nouvelles réponses, regroupées, option du sondage activée par défaut ; les répondants connectés reçoivent l'annonce de la date retenue.

## Pourquoi

Sans email, le créateur doit revenir voir, et les répondants ignorent la décision. Seuls les répondants connectés sont prévenus : le service ne connaît pas l'adresse d'un pseudo.
