# Changer les jours proposés

_Source : spec.md, Clarifications._

## Décision

Ajouter des jours reste toujours possible ; retirer un jour n'est permis que s'il ne porte aucun vote.

## Pourquoi

Retirer un jour voté effacerait en silence la réponse de quelqu'un. La base le garantit elle-même : un vote tient son jour par une clé étrangère (décision 027).
