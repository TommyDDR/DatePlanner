# Répondant connecté dont l'appareil porte une réponse anonyme

_Source : spec.md, Clarifications._

## Décision

Connecté, il voit le sondage avec son compte ; déconnecté, il le voit en mode anonyme, avec la réponse de son appareil.

## Pourquoi

Fusionner les deux réponses supposerait qu'un appareil appartient à une seule personne, ce qu'un poste partagé dément. Chaque identité garde sa réponse ; la réponse anonyme reste comptée dans la synthèse.
